# PokéFinder

## Autor

Anna Helena Soares Rocha – Matrícula 22606470

## Descrição

O PokéFinder é uma aplicação web frontend que permite pesquisar Pokémon pelo nome ou número e consultar informações de forma organizada. A aplicação é útil para usuários que desejam encontrar rapidamente dados básicos de diferentes Pokémon.

## API utilizada

- **PokéAPI:** https://pokeapi.co/
- **Documentação:** https://pokeapi.co/docs/v2
- **Endpoint consumido:** https://pokeapi.co/api/v2/pokemon/{nome-ou-id}

A aplicação utiliza `fetch` para realizar uma requisição assíncrona, recebe a resposta em JSON e apresenta os dados na página.

## Funcionalidades

- Pesquisar Pokémon pelo nome.
- Pesquisar Pokémon pelo número.
- Exibir nome e número da Pokédex.
- Exibir imagem do Pokémon.
- Exibir tipos.
- Exibir altura.
- Exibir peso.
- Exibir experiência base.
- Exibir quantidade de habilidades.
- Informar o usuário quando o Pokémon não é encontrado.
- Informar o usuário quando o campo de busca está vazio.
- Realizar a pesquisa pelo botão ou pela tecla Enter.
